Sizzle & Serve — a fast-paced top-down kitchen game: take orders from the board, chop, fry and plate dishes against the clock, then serve them at the pass before the tickets run out.

## Run it

```sh
python3 -m http.server --directory game 8080
```

Then open http://localhost:8080 — move with WASD or arrows, interact with E or Space, pause with P, mute with M.
